# 🖥️ Déploiement d'un serveur GLPI

Procédure de déploiement de **GLPI 10.0.20** (gestion de parc informatique et helpdesk) sur **Debian 12** avec une pile **LAMP**. Projet réalisé en BTS SIO.

## 📄 Contenu du dépôt

| Fichier | Description |
|---|---|
| `GLPI IDIR SEHRANE.pdf` | Documentation complète, étape par étape, avec captures d'écran |

## 🧱 Étapes couvertes

1. Installation et configuration de **Debian 12**
2. Installation de la pile **LAMP** (Apache2, MariaDB/MySQL, PHP et ses extensions)
3. Création de la base de données et de l'utilisateur GLPI
4. Téléchargement et installation de **GLPI 10.0.20**
5. Assistant d'installation web et premiers paramétrages
6. Sécurisation (suppression du fichier `install/`, changement des mots de passe par défaut)

## 🛠️ Technologies

Debian 12 · Apache2 · MariaDB · PHP · GLPI 10
